# 📊 파이썬 포트폴리오 최적화 & 효율적 프론티어 자동화 도구

원하는 주식 종목들의 과거 3년 치 수정종가 데이터를 자동으로 수집하여 **몬테카를로 시뮬레이션**과 **Scipy 수학적 최적화(SLSQP)**를 수행하고, 도출된 **효율적 프론티어(Efficient Frontier)** 및 **자본배분선(CAL)** 차트와 상세 데이터를 엑셀 리포트(`.xlsx`)로 자동 생성하는 파이썬 프로젝트입니다.

---

## ✨ 주요 기능

1. **금융 데이터 자동 수집 (`yfinance`)**
   * 한국 주식(`.KS`, `.KQ`) 및 미국 주식 등 개수 제한 없이 다중 종목의 최근 3년 치 기말수정종가 수집
   * 무위험자산(Risk-Free Asset) 기준점으로 미국채 10년물 금리(`^TNX`) 실시간 반영
2. **수익률 및 분산-공분산 행렬 연산 (`pandas`, `numpy`)**
   * 일별 수익률 산출 및 연간 거래일(252일) 기준 연율화 기대수익률, 분산-공분산 행렬(Covariance Matrix) 계산
3. **몬테카를로 포트폴리오 시뮬레이션**
   * 행렬 곱 연산을 활용해 10,000개의 무작위 가중치 포트폴리오를 고속 시뮬레이션하여 위험-수익 분포 파악
4. **수학적 포트폴리오 최적화 (`scipy.optimize`)**
   * 제약 조건($\sum w_i = 1$, 공매도 금지 $0 \le w_i \le 1$) 하에서 비선형 계획법(SLSQP)을 통한 정확한 해 도출
   * **시장 포트폴리오 (Tangency Portfolio):** 샤프 지수(Sharpe Ratio) 최대화 비중 산출
   * **최소 분산 포트폴리오 (Minimum Variance Portfolio):** 변동성 최소화 비중 산출
   * **효율적 프론티어 곡선:** 50개 목표 수익률 구간별 최소 변동성 지점 계산
5. **엑셀 리포트 & 고해상도 차트 자동 생성 (`openpyxl`, `matplotlib`)**
   * 모든 단계의 계산 데이터와 스타일링(퍼센트 포맷, 헤더 디자인, 열 너비 자동 맞춤)이 적용된 엑셀 파일 출력
   * 산점도, 효율적 프론티어 곡선, 자본배분선(CAL)이 결합된 차트를 엑셀 요약 시트 내에 이미지로 자동 삽입

## 📐 핵심 수식 요약

* **포트폴리오 기대수익률:** $E(R_p) = w^T \mu$
* **포트폴리오 변동성(표준편차):** $\sigma_p = \sqrt{w^T \Sigma w}$
* **샤프 지수(Sharpe Ratio):** $SR = \frac{E(R_p) - R_f}{\sigma_p}$
* **자본배분선(CAL) 방정식:** $E(R_{CAL}) = R_f + \left(\frac{E(R_m) - R_f}{\sigma_m}\right) \sigma_{CAL}$
